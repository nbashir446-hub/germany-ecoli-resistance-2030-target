# AMR results: 3rd-generation cephalosporin-resistant E. coli, 8 EU countries, 2015-2024
Source: ECDC EARS-Net / Surveillance Atlas; official baselines and 2030 targets from ECDC country data (EU Council Recommendation 2023/C 220/01). Calculated incidence = reported resistant isolates / population x 100,000 (not the official ECDC incidence).

## Official incidence per 100,000 vs 2030 target

- Italy: 2019 baseline 23.0, latest (2022) 17.3, change -24.7%, 2030 target 20.2 (-12% vs baseline, reduction), status: on track (at or below target).
- Denmark: 2019 baseline 6.6, latest (2023) 5.61, change -15.1%, 2030 target 6.3 (-5% vs baseline, reduction), status: on track (at or below target).
- Germany: 2019 baseline 12.0, latest (2023) 10.2, change -14.9%, 2030 target 10.6 (-12% vs baseline, reduction), status: on track (at or below target).
- Austria: 2019 baseline 7.1, latest (2023) 6.6, change -7.6%, 2030 target 6.4 (-10% vs baseline, reduction), status: above target.
- Netherlands: 2019 baseline 4.5, latest (2022) 4.3, change -5.4%, 2030 target 4.5 (+0% vs baseline, maintain_baseline), status: on track (at or below target).
- Sweden: 2019 baseline 9.2, latest (2023) 9.1, change -1.7%, 2030 target 8.3 (-10% vs baseline, reduction), status: above target.
- Poland: 2019 baseline 7.4, latest (2023) 7.8, change +4.4%, 2030 target 6.7 (-10% vs baseline, reduction), status: above target.
- Spain: 2019 baseline 7.8, latest (2022) 10.2, change +29.5%, 2030 target 7.1 (-10% vs baseline, reduction), status: above target.

## Linear regression of % resistant on year (slope in percentage points per year)

- Poland: slope +0.707 points per year.
- Spain: slope +0.389 points per year.
- Netherlands: slope +0.248 points per year.
- Sweden: slope +0.143 points per year.
- Austria: slope -0.032 points per year.
- Denmark: slope -0.090 points per year.
- Germany: slope -0.191 points per year.
- Italy: slope -0.524 points per year.
- Germany's fit is weak (R2 = 0.28): % resistant rose until 2017 then fell. Slopes show direction, not forecasts.

## % resistant isolates and calculated incidence per country (2015, 2019, 2024)

- Austria: % resistant 9.7 (2015), 9.3 (2019), 10.6 (2024); calculated incidence 5.5, 6.4, 7.1 per 100,000.
- Denmark: % resistant 7.5 (2015), 7.5 (2019), 6.8 (2024); calculated incidence 6.0, 6.6, 6.1 per 100,000.
- Germany: % resistant 10.3 (2015), 11.5 (2019), 10.6 (2024); calculated incidence 1.1, 3.3, 6.0 per 100,000.
- Italy: % resistant 30.1 (2015), 30.9 (2019), 27.7 (2024); calculated incidence 2.8, 9.5, 14.9 per 100,000.
- Netherlands: % resistant 6.1 (2015), 7.5 (2019), 9.1 (2024); calculated incidence 2.5, 3.2, 4.6 per 100,000.
- Poland: % resistant 11.9 (2015), 17.1 (2019), 18.8 (2024); calculated incidence 0.5, 1.3, 1.9 per 100,000.
- Spain: % resistant 11.6 (2015), 14.1 (2019), 16.8 (2024); calculated incidence 1.6, 2.5, 3.6 per 100,000.
- Sweden: % resistant 6.2 (2015), 7.8 (2019), 9.4 (2024); calculated incidence 3.8, 7.3, 9.4 per 100,000.

## Key findings

- Germany is on track: official incidence fell 14.9% from 12.0 (2019) to 10.2 (2023), below its 2030 target of 10.6.
- Italy, Denmark, Germany and the Netherlands are at or below target. Austria, Sweden, Poland and Spain are above target; Spain moved the wrong way (+29.5%).
- % resistant and incidence can move in opposite directions: Italy's % resistant fell (30.1 to 27.7) while its calculated incidence rose (2.8 to 14.9).
